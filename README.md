========================================================================
   Ext4TC: Ext2/3/4 Filesystem Plugin for Total Commander v2.0.1
========================================================================

ОПИС / DESCRIPTION:
-------------------
Ext4TC (v2.0) — це високопродуктивний плагін файлової системи (WFX) для 
Total Commander (x64), який дозволяє здійснювати безпосередній доступ, 
навігацію та читання з лінуксових розділів Ext2/3/4, образів дисків (.img) 
та віртуальних жорстких дисків (.vhd) прямо з середовища Windows.

Проєкт розроблено в рамках курсової роботи з системного програмного забезпечення.

ВСТАНОВЛЕННЯ / INSTALLATION:
----------------------------
Варіант 1 (Автоматичний):
1. Відкрийте Total Commander.
2. Зайдіть всередину архіву `ext4tc_v2.0.zip`.
3. Total Commander автоматично розпізнає плагін і запропонує його встановити. 
   Погоджуйтесь та виберіть каталог.

Варіант 2 (Ручний):
1. Скопіюйте файл `ext4tc.wfx64` у зручну для вас папку плагінів (наприклад, `%COMMANDER_PATH%\Plugins\wfx\ext4tc\`).
2. У Total Commander перейдіть: Конфігурація -> Налаштування -> Плагіни.
3. У розділі "Плагіни файлової системи (.WFX)" натисніть "Налаштувати".
4. Натисніть "Додати" та вкажіть шлях до файлу `ext4tc.wfx64`.

ВИКОРИСТАННЯ / USAGE:
---------------------
1. У панелі дисків Total Commander перейдіть до "Мережевого оточення" (Network Neighborhood / `\\Network`).
2. Відкрийте папку `[Ext2/3/4 Filesystem]`.
3. Для підключення нового лінуксового образу чи диска натисніть на елемент:
   `💿 < Монтувати новий том >` (або скористайтеся комбінацією `Alt + Enter` на кореневому каталозі для виклику глобальних налаштувань).
4. У діалоговому вікні виберіть шлях до вашого файлу VHD/IMG, за потреби виберіть мову інтерфейсу (Українська / English) та режим безпечного читання.

СТРУКТУРА СКОМПІЛЬОВАНОГО ПАКЕТУ:
---------------------------------
* `ext4tc.wfx64`   - основний 64-бітний бінарний файл плагіна (включає зашиту іконку та локалізацію).
* `pluginst.inf` - службовий файл-інструкція для автоматичного встановлення плагіна в Total Commander.
* `README.txt`   - цей файл інструкції.
