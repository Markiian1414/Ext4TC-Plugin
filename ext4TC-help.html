File System Plugin (WFX) for Total Commander · Ext2 / Ext3 / Ext4 · Windows x64

ОписDescription

Ext4TC — плагін для Total Commander, що надає прямий доступ до Linux-розділів Ext2/3/4, образів дисків .img та віртуальних дисків .vhd прямо з Windows. Не потрібно встановлювати драйвери або завантажувати Linux.

Ext4TC is a Total Commander plugin for direct access to Linux Ext2/3/4 partitions, disk images .img, and virtual drives .vhd — directly from Windows. No drivers or Linux boot required.

Проєкт розроблено в рамках курсової роботи з системного програмного забезпечення.

Developed as a coursework project in system software engineering.

FAQ

Плагін не бачить фізичні диски
Plugin doesn't see physical drives

Запустіть Total Commander від імені Адміністратора (ПКМ → «Запустити від імені адміністратора»).

Run Total Commander as Administrator (right-click → "Run as administrator").

Помилка «No Ext2/3/4 filesystem found»
Error "No Ext2/3/4 filesystem found"

Перевірте: правильний індекс диска (PhysicalDrive0, 1…), файл є сирим образом (не ISO/VMDK), образ не пошкоджений.

Check: correct drive index (PhysicalDrive0, 1…), file is a raw image (not ISO/VMDK), image is not corrupted.

Кирилиця в іменах файлів відображається некоректно
Cyrillic filenames display incorrectly

Переконайтесь, що в налаштуваннях плагіна обрано кодування UTF-8.

Make sure UTF-8 encoding is selected in plugin settings.

Як змінити мову інтерфейсу?
How to change the interface language?

Перейдіть у кореневу папку плагіна → натисніть Alt + Enter → оберіть мову → OK.

Go to the plugin root → press Alt + Enter → choose language → OK.
